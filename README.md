# AthleeLive Lite

野球のスコアを配信画面（OBS）に出すための、**1画面だけの簡易アプリ**。
スマホで B・S・O と走者と得点を押すと、OBS のオーバーレイがその場で変わる。

名簿・読み上げ・広告・球速はあつかわない。それらが要る試合は
本体（[baseball-overlay](https://github.com/athleelive-code/baseball-overlay)）を使う。

## 画面

| URL | 画面 | 使う人 |
|---|---|---|
| `/` | コントローラー | スコアを付ける人（スマホ） |
| `/overlay.html` | オーバーレイ | OBS のブラウザソースに貼る |

## 使い方

1. スマホで `/` を開き、チーム名を入れる
2. OBS に「ブラウザソース」を追加し、URL に `/overlay.html` を入れる（幅1920・高さ1080）
3. あとはスマホを押すだけ

### 操作

- **B・S・O** … タップで1つずつ増える。4ボールで押し出し（満塁なら1点）、
  3ストライクで1アウト、3アウトで自動的に攻守交代
- **走者** … ダイヤモンドの塁をタップ
- **得点** … 各チームの ＋／− で、今の回のマスに入る
- **1手戻す** … 直前の操作を取り消す（60手ぶん）
- 状態は端末に保存されるので、読み込み直しても続きから使える

### オーバーレイの見た目を変える

URL のうしろに付ける。

| 付けるもの | 意味 |
|---|---|
| `?pos=tl` | 置く場所。`tl` 左上（既定）／`tr` 右上／`bl` 左下／`br` 右下 |
| `?scale=1.2` | 大きさ（既定は 1） |
| `?line=1` | イニングスコア表も出す |
| `?demo=1` | つながっていなくても見本を出す（位置合わせ用） |

例： `/overlay.html?pos=tl&scale=1.2&line=1`

## 動かす

```
npm install
npm start
```

`http://localhost:3000/` がコントローラー、`http://localhost:3000/overlay.html` がオーバーレイ。

## デプロイ（Render）

1. GitHub にこのリポジトリを置く
2. Render で「New → Web Service」→ このリポジトリを選ぶ
3. Build Command `npm install` ／ Start Command `node server.js`（`render.yaml` があるので自動で入る）

無料プランはしばらく使わないと眠るので、試合前に一度開いて起こしておくとよい。

## しくみ

- `server.js` … ページを配るのと、つながっている画面へメッセージを配り直すだけ。
  最後の状態を12時間だけ預かるので、オーバーレイをあとから開いても続きが出る
- `public/link.js` … 画面どうしのつなぎ。ふだんは WebSocket。
  同じブラウザで開いた画面には BroadcastChannel でも届くので、
  サーバーが眠っていても手元の2画面は動く
- 送っているのは `{t:'state', s:{...}}` だけ。オーバーレイは開いたときに
  `{t:'hello'}` で今の状態を頼む
